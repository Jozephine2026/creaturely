creaturely

An interactive glossary of large language models, made as part of creaturely, a research-creation project by Alexandra Emberley developed in collaboration with an LLM. Ten pages follow a single line of a code poem, the echo of a beam never sent, through the processes that produced it: tokens and embedding, vectors, attention, neurons and layers, inference, sampling and temperature, training, superposition, stigmergy, and emergence.

The site begins at index.html. Not yet public.
