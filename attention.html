creaturely: a glossary · iii

attention

How tokens shape one another in context.

The first two entries of the glossary showed how a sentence is divided into tokens, how each token receives a vector, and how those vectors can be compared and subtracted. So far, however, each token has been represented only by its initial embedding: a vector learned during training and retrieved whenever that token appears.

Once these initial vectors have been retrieved, they pass into a transformer: the layered neural network architecture at the centre of most contemporary LLMs. As the sentence passes through its layers, the transformer repeatedly updates the representation of each token in relation to its context. The token beam begins with the same embedding whether the sentence concerns light or oak, but it does not remain there. Attention is one of the main processes through which its meaning changes.

i · attention weights

Within each transformer layer, attention calculates connections among the token positions. The connections are not made by following a set of written rules about grammar or meaning.

In a text-generating LLM, each token uses attention to look back across the tokens available within its context window. It can attend to itself and to the tokens that come before it, but not to tokens that come after. The context window is the stretch of text available to a model at one time. Anything outside that window cannot receive an attention weight. A context window is not the same as a chat window; it often includes the entire conversation so far, or a summary of it.

For each allowed connection, the model calculates a score. To do this, it transforms the current token’s vector into a query and transforms each available token’s vector into a key. Comparing a query with each key produces a set of scores indicating which earlier positions may be the most relevant to the token being updated.

These scores are then converted into attention weights. For one token, in one attention head, the weights are non-negative and together must add up to one. A larger weight means that a position contributes more to the next step; a smaller weight means that it contributes less. The model learns the transformations used to calculate these scores during training. A transformation here is a learned table of numbers, called a matrix, that converts one vector into another; the query and the key are each produced by applying a different matrix to a token’s current vector, and the numbers in those matrices are set during training.

In the visualization below is the sentence the echo of a beam never sent. Press a word to see one pattern of attention for its position. Each of the lines points to a token that it is allowed to draw information from. A stronger line represents a larger attention weight. Because a text-generating transformer is designed to predict what comes next, a later position can draw on earlier ones, but an earlier position cannot draw on words that have not yet appeared.

In this example, sent gives much of its attention weight to echo and beam, and less to words such as the and a. Because sent occurs near the end of the line, all of these earlier positions are available to it.

Echo, by contrast, can attend only to the and to itself. It cannot yet attend to beam or sent, because those tokens come later in the sequence.

These weights do not imply that the model is consciously aware of one word more than another. They are numerical proportions used to decide how strongly information from each available position will contribute to the next representation.

The resulting pattern reflects regularities in grammar, meaning, tone, or use that the model absorbed from the examples used during training. This does not mean that the model has learned explicit rules about language or meaning, or that it applies a separate attention to grammar, meaning, or tone. The same attention mechanism can contribute to many kinds of relationship at once, while other calculations within each transformer layer also help shape the token’s updated representation.

ii · contextual representations

The attention weights are not an end in themselves. They only determine how the information from the available tokens is combined.

The model transforms each available token’s current representation into another vector called a value. It multiplies each value by its attention weight and adds the weighted values together. A value given a larger weight contributes more strongly to the result.

This combined information is used to update the representation of the token doing the attending. If beam gives substantial weight to an earlier occurrence of light, information carried by light will have a larger influence on beam’s next representation.

If we picture vectors as positions, this is where the starting positions begin to move. After attention and the other calculations within a transformer layer, a token is represented not only by its initial embedding but by a vector adjusted to its particular context. In light gathered into a beam, the preceding words draw beam toward illumination. In the roof rested on an oak beam, roof and oak draw it toward timber and construction.

The adjusted vector is often called a contextual representation. It is created for the specific occurrence of the token as the sentence passes through the model. It is not stored as a new definition of beam, nor does it permanently alter the token’s initial embedding. A new context will produce a new representation.

This is one reason why the order and company of your words matter when you write to an LLM. You are not simply selecting from or tapping into fixed meanings like you might find in a dictionary. You are arranging a context from which the model then constructs a representation for each position.

In a transformer, attention runs in layer after layer, not only once. Contemporary LLMs may contain dozens or more than a hundred such layers. Within each layer, the model calculates attention patterns, combines information, and performs further transformations. The resulting representations pass into the next layer, where the process begins again.

By the later layers, a token can carry information gathered from many earlier positions in the available context. Its vector has become a record not only of which token it is, but of how that occurrence is being used here.

The reading accumulates

A transformer is many of these layers stacked. Each one does not replace the surface beneath it; it adds its reading to a running one. The result is a worked surface, re-inscribed with every pass, never wiped clean.

Six layers, one query. The earliest reading sits at the bottom, faint; each later layer settles on top of it. The crisp sheet is the layer you are looking at now — tap a sheet to move there. Freud called the analogous thing a mystic writing pad: a surface that keeps the trace of everything written on it while always presenting a clean face.

Field, not sequence

A loom builds a row at a time, and a needle commits one stitch before the next. Attention has no such order. Every patch is weighed against every other in a single parallel pass, and geometry has to be told to it through a position signal rather than given by the cloth. The grid above is not a path the model walks. It is the relation it computes all at once.

Where the surprise lives

The weights are not authored by hand in a real model; they are learned. So the groupings a patch reaches for, what counts as alike, what holds an edge, are not ones you specified. When making-with such a system returns something you did not put there, this is the room it came out of: the learned pattern of attention, legible after the fact, the way a worked surface can be reread once it is still.

a note on the visualizations

Every visualization in this glossary is an approximation. The panels were built by hand to illustrate an idea; they were not computed by a working model, and real LLMs are larger, less tidy, and less legible than anything shown here. Their purpose is to bridge the gap between the complexity of an LLM’s inner workings and human experience, which is what a good visualization tends to do.

notes on this page

The attention weights on this page were set by hand to illustrate the idea. A working LLM calculates queries, keys, values, and attention weights from its current representations using transformations learned during training.

For each token, each attention head produces its own set of weights. The weights within that set add up to one, making them relative proportions within the weighted combination. This mathematical normalization is the only sense in which attention behaves like a fixed “budget”; it does not describe a literal quantity of awareness or notice.

An attention weight is not a general measure of how important a word is to the model’s response. It describes one connection involving one token, in one attention head, at one layer of the transformer.

Real transformers calculate several attention patterns at once, using multiple heads, and repeat the process across many layers. Different heads can form different patterns of connection. No single attention pattern determines a token’s representation on its own.

The flowing particles in the interactive illustrate the weighted combining of information; they are not a picture of anything physically moving inside the model. The beam panel also compresses many heads, layers, and additional calculations into one hand-drawn movement.

Attention is not the only process that alters a token’s representation. Each transformer layer contains other transformations, introduced in the next entry, and preserves information through connections that this page leaves aside. Positional information, which allows the model to distinguish where tokens occur in the sequence, is also omitted from the teaching diagrams.
